# User Test Script (Moderator)

**Owner:** Yang Zhao  
**Date:** 16/02/2026  
**Scope:** Homepage (Search + results info + status + navigation)

## Opening (read aloud)
Hi, thanks for helping! We’re testing the system, not you.  
Please think aloud as you go—tell me what you’re trying to do and what you expect to happen.  
If you get stuck, that’s useful feedback for us. You can stop anytime.

## Tasks
### T1 – Find the search entry point
You want to find a book. Where would you start on this page?

### T2 – Search by book title
Search for a known title (e.g., “Harry Potter”). How would you submit the search?

### T3 – Search by author
Search for an author (e.g., “J.K. Rowling”). Do you think author search is supported?

### T4 – Typo / partial input
Misspell the title by 1–2 letters and search again. What do you do next?

### T5 – No results feedback
Search for a nonsense term (e.g., “asdfghjkl”). What do you think is happening?

### T6 – Empty input behaviour
Try searching with an empty input. What do you expect the system to do?

### T7 – Understand listing info (without opening details)
Without opening details, tell me: Title, Author, Year, ISBN, and Availability.

### T8 – Find navigation/entry points
Show where you would go to:
1) Login / Sign Up
2) Reservations
3) Checkout history
4) Settings

## Wrap-up
If you could change one thing on this page to make it easier, what would it be?
